# Personal CV Website

This repository contains my personal CV presented as a responsive website. It was created as an HTML and CSS course project.

## Live website

The deployed website is available here:

[https://michaelharbst.github.io/CV/](https://michaelharbst.github.io/CV/)

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media queries for responsive design
- GitHub Pages for deployment

## Features

- Two-column CV layout for larger screens
- Responsive single-column layout for smaller screens
- Print styling for saving or printing the CV as a PDF
- Contact links for email and telephone
- Separate sections for skills, education, certifications and work experience
- CSS variables for consistent colours and easier design changes
